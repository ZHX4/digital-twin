# Ethical Design Principles

1. **No genetic determinism:** the synthetic genome is a bounded prior, never a final classifier.
2. **Reversibility:** recommendations are not identity assignments.
3. **Visible uncertainty:** entropy and confidence remain exposed.
4. **Exploration before exclusion:** uncertainty triggers information gathering.
5. **Human review:** high-impact changes require human review.
6. **Data minimization:** retain only synthetic information needed for experiments.
7. **Auditability:** major decisions produce structured audit records.
8. **Counterfactual scrutiny:** interventions are compared against alternatives.
9. **No protected-class targeting:** the fairness lab uses synthetic resource strata.
10. **Model humility:** outputs are model behavior, not empirical truth.
