# Contributing

## Good contributions

- new learner-state models;
- alternative knowledge-tracing models;
- calibration against properly licensed educational datasets;
- stronger counterfactual estimators;
- fairness diagnostics;
- reproducibility tooling;
- documentation and threat-model improvements.

## Before submitting

```bash
pytest
make research
```

Every new model should document assumptions, inputs, outputs, uncertainty and failure modes.
