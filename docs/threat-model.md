# Threat Model

| Threat | Mechanism | Mitigation |
|---|---|---|
| Genetic determinism | strong prior dominates evidence | genomic cap + ablation + audit |
| Automation bias | users trust one score | posterior + uncertainty + governance |
| Feedback loop | prediction creates evidence | counterfactual lab |
| Model drift | environment changes | versioning + recalibration |
| Hidden bias | unequal resources | equity lab |
| False precision | probability treated as truth | calibration diagnostics |
| Premature specialization | early posterior becomes policy | exploration + reversibility |
| Data overcollection | unnecessary collection | synthetic-only baseline |
| Market chasing | curriculum follows volatile demand | market separated from learner state |
| Objective mismatch | speed harms wellbeing | multi-objective gate |
