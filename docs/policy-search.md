# Policy Search Laboratory

A policy is represented by:

- specialization age;
- acceleration;
- exploration budget;
- mentorship;
- teacher ratio;
- resource equalization;
- tutor availability;
- core-learning ratio.

The search objective is multi-objective. There is intentionally no universal scalar winner.

## Objectives

Maximize learner competency, wellbeing, agency and equity index.

Minimize mismatch risk, resource inequality and cost proxy.

A candidate is Pareto-dominated when another candidate is at least as good on every objective and strictly better on at least one.

## Interpretation

The Pareto frontier is a set of trade-offs inside the simulator. It is not a recommendation for real educational policy.
