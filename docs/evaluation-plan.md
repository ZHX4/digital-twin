# Evaluation Plan v4

## Engineering

- deterministic replay;
- bounded outputs;
- schema validation;
- compile/import checks;
- API contract checks;
- regression tests;
- reproducible research-pack manifests.

## Learner model

Compare learner-state models on predictive error, calibration, retention, transfer and uncertainty.

## World model

Evaluate population distributions rather than single trajectories. Report quantiles and bootstrap intervals for competency, wellbeing, agency and mismatch.

## Policy search

Evaluate frontier stability across seeds, population sizes and objective weights.

## Equity

Measure resource-stratum gaps and sensitivity to resource equalization.

## Synthetic-to-real boundary

The current world is not externally validated. Future real-data calibration must document dataset licensing, preprocessing, measurement validity, distribution shift and ethical review.
